## 🌟 核心亮点

### 1. 纯正 Apple HIG 物理毛玻璃 & 灵动悬浮岛
* **网页真透视悬浮岛（Alt + W）**：通过浏览器底层 **Shadow DOM 沙盒机制**，将一枚拥有 **26px 液态超椭圆连续曲率大圆角** 的倒计时小组件直接悬浮在你当前浏览的任何网页上，绝不破坏宿主网页样式，亦不受宿主 CSS 干扰。
* **0% ~ 100% 无级空气毛玻璃滑块**：
  * **0%（完全透明空气形态）**：外壳背景彻底隐形，动态关闭模糊滤镜，背后的网页图文 100% 毫无遮蔽，倒计时数字与进度条如水波般漂浮于空中！
  * **20%~45%（轻透轻折射）**：柔和水波轻磨砂；
  * **65%（经典透润）**：标准 Apple 毛玻璃材质（`backdrop-filter: blur(20px) saturate(180%)`）；
  * **100%（实体纯色）**：简约白板。
* **自由拖拽与安全吸附**：鼠标按住顶部手柄可在屏幕任意四周拖动，松开智能吸附防出界。

### 2. 精准倒计时与科学排版
* **等宽跳动（Tabular Numbers）**：全面启用 `font-variant-numeric: tabular-nums`，彻底杜绝秒数变动时数字左右抖动，超细苹果字重呼吸感拉满。
* **8px 原生药丸胶囊进度条**：告别生硬线条，采用双圆角槽体与主题渐变高光光晕。
* **标准货币排版**：今日收益支持按日薪/月薪自适应计算，强制规范为标准金融格式（如 `¥ 286.03`）。
* **自适应小组件矩阵**：发薪日、周五倒计时、法定节日、自定义纪念日自适应排布为对称方块矩阵。

### 3. 月历视图与法定节假日自动同步
* **月度日历看板**：一键切换月历，清晰标识当前日期。
* **法定节假日 & 调休补班微标**：自动标注“假”（放假）与“班”（调休补班），打工人放假安排一目了然。

### 4. 极致交互与隐私安全
* **iOS 原生级 Auto-Save（无感即时自动保存）**：任何皮肤切换、滑块拖动、开关拨动均毫秒级自动静默持久化至 `chrome.storage.sync`，彻底告别“忘记点保存”的负担。
* **100% 纯本地离线运行**：零数据上传、零外部埋点，所有配置与计算均在本地浏览器闭环，恪守数据隐私合规。

### 5. v1.5 新增：专注、胶囊与周视角
* **专注模式（勿扰时段）**：设定时段内自动静音所有提醒，开会 / 深度工作时绝不打扰；支持跨午夜时段（如 22:00 → 06:00）。
* **悬浮岛胶囊形态**：双击网页灵动岛即收缩成屏幕顶部的一枚小胶囊（仅保留时间），再次双击展开——优雅不挡视野。
* **本周剩余工时横幅**：实时统计从此刻到本周最后一个工作日的剩余工时（自动排除节假日与调休），发薪日动力 +1。

## 🛠️ 安装与使用

### 方式一：加载已解压的扩展程序（开发者模式）
1. 克隆或下载本仓库至本地文件夹：
   ```bash
   git clone https://github.com/2436136932/Countdown-to-Off-work-Browser.git
   ```
2. 打开 Chromium 浏览器（Chrome、Edge、Tabbit、Brave 等），在地址栏访问扩展管理页：
   * Chrome / Tabbit: `chrome://extensions`
   * Edge: `edge://extensions`
3. 开启右上角的 **「开发者模式 (Developer mode)」**；
4. 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」**，选择本项目的 `offwork-countdown` 文件夹；
5. 在浏览器工具栏找到「下班倒计时」图标并固定。
